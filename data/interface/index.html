Drawing options

Auto-save drawings

The drawing saves itself while you draw. Default is on.

Text tool

Adds a text tool; click the canvas, then type. Default is off.

Eraser tool

Clicking an object deletes it while active. Default is off.

Drag-to-size shapes

Press and drag to size a new shape as you draw it. Default is off.

Simplify interface

Show only the options for the active tool. Default is off.

Page screenshot layer

Places a page screenshot under the drawing. Default is off.

Page scroll

Sticks drawings to the page content while scrolling. Default is off.

Keyboard shortcuts

Draw without the panel using keys. Default is off.

UI font

Font used across this panel.

UI size

Scale of the panel text.

Keyboard shortcuts

Show panel

Show or hide the panel while drawing continues.

Pencil

Switch to the pencil brush.

Eraser

Requires the eraser tool to be enabled.

Move

Switch to the move tool.

Undo

Removes the last drawing step.

Redo

Restores the last removed step.

Text tool

Requires the text tool to be enabled.

Copy

Copies the selected object.

Paste

Pastes the copied object.

Download

Saves the drawing as an image.

Zoom in

Zooms the drawing in one step.

Zoom out

Zooms the drawing out one step.
